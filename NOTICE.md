# Data and Use Notice

- CivilComments-WILDS v1.0 is listed by the official WILDS dataset page as
  public domain / CC0. Preserve attribution to the CivilComments and WILDS
  papers and retain this notice when referring to the source dataset.
- The WILDS archive contains public online comments and sensitive toxicity and
  identity-mention annotations. Raw comments, row-level predictions, and model
  artifacts are excluded from this repository. The dashboard uses aggregate
  evaluation metrics and does not display dataset examples.
- The eight WILDS group fields indicate identity mentions in a comment; they
  are not labels of the author's identity. Group metrics therefore describe
  model errors on annotated text subpopulations, not fairness for demographic
  groups of people.
- This repository's code is MIT-licensed. Dataset terms are separate.
- The project is a research and interview demonstration. It is not a moderation
  service or a basis for consequential decisions about individuals.
